# A web funnel dataset for a subscription-based product.

## Overview

This notebook presents the analysis of a web funnel dataset for a subscription-based product.  

The objective of the assignment is to:

1. Analyze user progression through the web funnel.
2. Identify the most promising experiments.
3. Evaluate monetization implications under limited revenue data.
4. Assess differences across funnel types.
5. Prioritize funnel stages from a subscription economics perspective.

The focus of this analysis is on:
- Business logic
- Monetization thinking
- Experiment prioritization
- Decision-making under data constraints

## Dataset Description

The dataset contains user-level event data with the following key fields:

- `user_id`
- `event_type`
- `event_time`
- `event_params`

Key funnel stages:
- `funnel_start`
- `profile_start`
- `email_submit`
- `paywall_show`
- `payment_done`
- `experiment_exposure`

The product follows a subscription-based monetization model.

## Analytical Approach

The analysis is structured into the following steps:

1. Data validation and structure overview
2. Funnel conversion analysis
3. Experiment evaluation
4. Monetization analysis and data limitations
5. Proxy metrics assessment
6. Funnel type segmentation
7. Funnel prioritization and growth strategy

## Important Note

Revenue data, pricing, retention, and subscription lifecycle information are not available in this dataset.
All monetization conclusions are therefore based on proxy metrics and funnel progression.
